You are about to hand this task off to another instance of the assistant, which will see only your summary and not the original conversation.
Write a handoff summary that lets it continue the work without asking the user again.

Include:
1. The user's goal, in their own words where possible.
2. What has been done so far, including the tools called and the important results.
3. Pending tasks: everything that still has to be done.
4. Next steps: the concrete next actions to take.

Be specific: keep names, amounts, IBANs, email addresses, dates and file names exactly as written.
